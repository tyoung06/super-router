Tool-shed key plan

1. Keep two keys: one in the lockbox by the gate, one with the shed lead.
2. Volunteers sign the lockbox sheet when they take or return the key.
3. A key not back by dark: the shed lead collects it the next morning.
4. The shed lead changes the lockbox code each season.
