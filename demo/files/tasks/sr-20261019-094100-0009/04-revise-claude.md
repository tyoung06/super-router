Pre-order plan

1. Make one shared sheet, editable by staff only, with columns: name, item, pickup day, paid.
2. Staff add each phone order the moment it comes in.
3. Turn on version history and keep a daily copy.
4. Print the next day's list at closing.

## Answered
A3: The column names are fixed in step 1, so this attack does not apply.
B2: A shared sheet saves each edit as it is typed, so two staff adding rows at once don't overwrite each other.
B3: Paid is yes or no; how it was paid isn't part of this plan.
